* Development Notes

** 2025-11-14: Complete Rewrite to WebSocket

Completely rewrote the protocol implementation after discovering:
1. Amp uses WebSocket, not UNIX sockets
2. Lockfile format is ={"port": X, "authToken": "Y", ...}=
3. Messages use IDE protocol format with wrappers
4. Notification names are specific (e.g., =visibleFilesDidChange=)

Key changes:
- Replaced make-network-process UNIX socket with WebSocket server
- Updated lockfile to JSON with port and token
- Wrapped all messages in proper IDE protocol format
- Changed notification names to match amp.nvim exactly
- Added readFile and editFile handlers
- Implemented proper file editing in buffers

Result: **Fully working integration!**

** Critical Learning

The protocol was completely different from initial assumptions:
- ❌ UNIX sockets → ✅ WebSocket (TCP)
- ❌ socket_path → ✅ port + authToken  
- ❌ Simple JSON → ✅ IDE protocol wrappers
- ❌ Custom message names → ✅ Standard IDE messages

Always check the reference implementation (amp.nvim) before assuming!

** Code Style
- Follow Emacs Lisp conventions
- Use lexical binding
- Document all functions
- Keep functions small and focused
- Add comments for complex logic

** Testing
Before submitting PR:
- Test with =amp --ide=
- Check with =M-x checkdoc=
- Verify byte-compilation clean
